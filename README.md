# Brightward

Official website for Brightward Consulting.

Brightward is a technical consulting firm focused on helping small and midsize organizations identify operational problems and turn them into practical digital solutions.

## Site Structure

- `index.html` — Home
- `approach.html` — How We Work
- `work.html` — Work / Case Studies
- `about.html` — About
- `styles.css` — Shared site styles
- `script.js` — Shared site interactions

## Current Branch Workflow

Development work is performed on the `Labib` branch before being reviewed and merged into `main`.

## Local Development

Because the current site is static HTML, CSS, and JavaScript, no package installation or build process is required.

Open `index.html` directly in a browser to preview the site.

For a more complete local development environment, the site can also be served through a lightweight local server such as VS Code Live Server.
